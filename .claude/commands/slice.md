Задача: $ARGUMENTS

1. Прочитай `AGENTS.md`, `docs/plan.md` и нужные разделы `docs/spec.md`. Загрузи подходящие скиллы из таблицы в `AGENTS.md`.
2. Напиши короткий план: файлы (создать/изменить), миграции/функции, как проверить на телефоне. Дождись моего «ок»,
   если план меняет схему БД или добавляет зависимость; иначе продолжай.
3. Реализуй маленькими шагами. Для актуального API библиотек используй Context7.
4. Запусти `npm run build && npm run lint && npm run test`. Исправь ошибки, не ослабляя проверки.
5. Запусти субагента `suutech-reviewer` и исправь блокеры.
6. Отметь пункты в `docs/plan.md`, сделай коммит `feat(<область>): ...`.
7. В конце: что сделано, как проверить руками с телефона, что осталось / `TODO-ky` ключи.
