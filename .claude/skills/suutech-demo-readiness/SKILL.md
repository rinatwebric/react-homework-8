# Готовность к демо SuuTech (ТЗ v2.0)

Источник: `docs/spec.md` §5, §15–§17. Главное правило: **на сцене показываем только то, что стабильно работает.**
Демо — про заявку жителя, карту повторяющихся проблем, триаж в админке и кнопку 112. Не про AI-сканер.

## Флаги (`src/config/features.ts`)
```ts
const flag = (v: string | undefined) => v === 'true';
export const features = {
  weather: flag(import.meta.env.VITE_FF_WEATHER),
  offline: flag(import.meta.env.VITE_FF_OFFLINE),
  triage: flag(import.meta.env.VITE_FF_TRIAGE),
  push: flag(import.meta.env.VITE_FF_PUSH),
  kyrgyz: flag(import.meta.env.VITE_FF_KYRGYZ),
} as const;
```
- P0 (форма без фото, гео с радиусом 300 м, карта пилота, кнопка 112, админка со статусами) — **без флагов**.
- P1+ (погода, офлайн-очередь, AI-триаж, push, кыргызские подписи) — за флагом, по умолчанию `false`.
- Флагов `farmer`, `premium`, `sensors`, `waterVolume` больше нет: фичи удалены из ТЗ (§18).

## Демо-данные (всегда подписаны)
- 12–15 заявок `is_demo = true` по Ак-Өлөң: все категории, разные статусы, 2–3 пары похожих в радиусе 100 м,
  одна с `immediate_danger = true`. Сид — `supabase/seed.sql`, на карте бейдж «Демо».
- Погода — реальный Open-Meteo, прогрета перед выступлением (кэш TTL 30–60 мин).
- Аккаунт модератора проверен, `/admin` открывается на демо-телефоне.
- Запасная заявка уже на карте — если сеть упадёт во время живой отправки.

## Заморозка (за 6–8 ч до защиты)
- Только баги из чек-листа. Никаких новых фич, обновлений зависимостей и миграций.
- Тег `git tag demo-v1`; Vercel production указывает на этот коммит. SW не должен обновиться во время демо.
- Пролистать карту пилота на обоих телефонах (прогрев кэша тайлов), установить PWA, разрешить гео и уведомления.
- Проверить, что `.env` для прода содержит нужные `VITE_FF_*`, и что выключенные флаги реально скрывают UI.

## Чек-лист приёмки (§17)
- [ ] С телефона по QR: выбрать категорию, отправить **без фото** — заявка появилась на карте.
- [ ] Без геопозиции отправить нельзя; при отказе в доступе — инструкция, а не пустой экран.
- [ ] Маркер нельзя утащить дальше 300 м от GPS (проверено и на клиенте, и сервером).
- [ ] Авиарежим: заявка в очереди, после сети уходит сама, без дублей.
- [ ] На главной видны текущая погода и прогноз на 3 дня; при осадках — баннер.
- [ ] Кнопка «Позвонить 112» открывает набор номера, рядом текст «не заменяет экстренный звонок».
- [ ] `/admin`: AI предлагает категорию, срочность, резюме; кнопка «нужна проверка человеком» фильтрует.
- [ ] Модератор меняет категорию/срочность после AI — предложение не перезаписывается молча.
- [ ] Статус меняется `new → triaged → assigned → in_progress → resolved` и пишется в историю.
- [ ] Публичная карта не раскрывает точный адрес (в Network нет `lat`/`lng` из `reports`).
- [ ] Карта показывает слой областей/районов с плашкой «слой-ориентир, не прогноз».
- [ ] Демо-заявки подписаны бейджем «Демо».
- [ ] Ключи модели и `service_role` не видны в бандле и Network (`grep` по `dist/`).
- [ ] Android Chrome + iOS Safari; Lighthouse PWA/Performance ≥ 85 (мобильный профиль).
- [ ] Основной чанк ≤ ~200 КБ gzip; карта и админка — отдельные чанки.
- [ ] Нигде нет белого экрана: без сети, без гео, при 502 от AI, при пустой админке.
- [ ] Резервное видео демо записано; 3 репетиции проведены.

## Сценарий (3 минуты, §16)
1. Проблема, 30 с: сигналы жителей теряются, служба не видит повторяющиеся участки.
2. Житель, 45 с: погода → категория «стоячая вода» → фото пропускаем → гео → сдвиг метки внутри 300 м →
   авиарежим → «Отправить» (заявка в очереди).
3. Синхронизация, 20 с: сеть включена — метка на карте.
4. Админка, 45 с: AI предложил категорию и срочность, нашёл похожую заявку; модератор подтверждает →
   статус «назначена на проверку»; история обновилась.
5. Безопасность, 10 с: кнопка 112 и фраза «приложение не заменяет экстренный звонок».
6. Финал, 30 с: пилот в одном селе, бесплатно для жителей, платный мониторинг для айыл окмоту или грант.

## Ответы жюри (честно)
- «AI определяет подтопление по фото?» — нет. AI сортирует заявки в админке: категория, срочность, дубликаты.
  Решение принимает человек.
- «Это прогноз?» — нет. Погода справочная, слой районов — ориентир, не прогноз. Прогноз — дорожная карта (P2).
- «Зачем фото, если оно необязательно?» — это ускоряет проверку, но сигнал должен уходить и без него:
  у человека может не быть времени или света.
- «Кто платит?» — пилот: грант или муниципалитет; после пилота платит служба за карту, триаж и отчёты.
- «Почему не заменит 112?» — не должен: мы для неэкстренных наблюдений и приоритизации, экстренное — звонок.
