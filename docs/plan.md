# План HydroGuard KG — вертикальные срезы

> Каждый срез заканчивается тем, что можно показать **с телефона**. Агент отмечает `[x]` после проверки.
> Не начинай следующий срез, пока контрольная точка текущего не пройдена. Подробности — `docs/spec.md` §12.

## Срез 0 — каркас (1–2 ч) · скиллы: `hydroguard-offline-pwa`, `deploy-to-vercel`, `hydroguard-backend`
- [ ] Удалить код блога из урока; перевести проект на TypeScript strict (`tsconfig`, `.tsx`), Tailwind v4, структура из `AGENTS.md`
- [ ] Скрипты `build` (tsc + vite), `lint`, `test` (vitest), `typecheck`
- [ ] Роутер: `/`, `/scan`, `/map` (lazy), `/admin` (lazy), 404; error boundary; i18n (ru) с первым экраном
- [ ] `vite-plugin-pwa` (injectManifest, `src/sw.ts`), manifest, иконки
- [ ] Supabase: `supabase init`, первая миграция (таблицы, RLS, view, бакет), `.env.example`
- [ ] Деплой на Vercel, переменные окружения
- **Контрольная точка:** пустое приложение открывается по HTTPS-ссылке и ставится на телефон

## Срез 1 — AI-сканер (P0) · `hydroguard-ai-scanner`
- [ ] Камера/галерея, сжатие ≤1 МБ / 1280 px, удаление EXIF
- [ ] Edge Function `analyze-photo` + контракт zod + повтор + понятные ошибки
- [ ] Экран результата (риск цветом+иконкой+текстом, confidence, дисклеймер)
- [ ] Прогон 10–15 реальных фото → `docs/ai-test-photos.md`, выбрать 3–4 демо-фото
- **Контрольная точка:** с телефона фото → оценка за несколько секунд

## Срез 2 — геопозиция, отчёт, карта (P0) · `hydroguard-map-geo`, `hydroguard-backend`
- [ ] Обязательная геопозиция, предупреждение о точности, перетаскивание метки, экран «доступ запрещён»
- [ ] `submit-report` (идемпотентность `client_id`, лимиты)
- [ ] Карта `reports_public`: цветные метки, кластеры, карточка, фильтры
- **Контрольная точка:** фото → метка на карте с телефона

## Срез 3 — погода, /admin, офлайн (P1) · `hydroguard-weather`, `hydroguard-backend`, `hydroguard-offline-pwa`
- [ ] `weather-check` + баннер на главной (флаг `VITE_FF_WEATHER`)
- [ ] `/admin`: вход модератора, карта с точными координатами, таблица, фильтры, статусы с комментарием, статистика, CSV
- [ ] Офлайн-очередь IndexedDB, синхронизация, индикатор «Нет сети · в очереди: N», кэш тайлов (флаг `VITE_FF_OFFLINE`)
- **Контрольная точка:** авиарежим → отчёт → сеть → метка, без дублей

## Срез 4 — push (P1) · `hydroguard-web-push`
- [ ] Экран согласия, подписка, `subscribe-push`, `send-push`, кнопка тестового предупреждения в `/admin`

- **Контрольная точка:** push из админки на Android и установленной PWA на iPhone
