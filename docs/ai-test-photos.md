> Цель: убедиться, что оценка по фото осмысленна и стабильна, и выбрать 3–4 демо-фото для защиты.
> AI оценивает **видимые последствия** сырости, а не уровень грунтовых вод — это и проверяем.

## Как прогонять

Один и тот же файл — один запрос (кэш по SHA-256: повтор вернёт `cached: true` и не потратит квоту,
поэтому для нового прогона меняйте `client_id` и файл).

```bash
curl -s -X POST "https://<ref>.supabase.co/functions/v1/analyze-photo" \
  -H "apikey: <anon-key>" -H "Authorization: Bearer <anon-key>" \
  -F "file=@photos/01-damp-wall.jpg" -F "client_id=test-01" -F "lang=ru" -F "mode=resident"
```

Фото: реальные снимки пилота (Ак-Өлөң) с телефона, как их снимет житель — без обработки и фильтров.
Персональные данные (люди, номера машин, адреса) в репозиторий не кладём.

## Критерии приёмки

- [ ] Ни на одном фото нет `critical` — этот уровень ставится только правилами зоны и датчиков.
- [ ] Нерелевантное фото (кот, документ, пейзаж) даёт `is_relevant: false` и `risk_level: low`.
- [ ] Тёмное/смазанное фото даёт `confidence < 0.5` — экран просит переснять.
- [ ] Находки конкретны («тёмное пятно у плинтуса»), а не «возможно, проблема».
- [ ] Дисклеймер модели не утверждает, что измерен уровень грунтовых вод.
- [ ] Выбраны 3–4 демо-фото, которые дают разный риск (`low` / `medium` / `high`) и лежат в `public/demo/`.
